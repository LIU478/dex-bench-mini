A mini benchmark for dexterous hand teleoperation in simulation.
Built on **Isaac Lab + dex-retargeting + LeRobot**.
## Project Goals
- End-to-end teleoperation pipeline: input → retargeting → sim → data
- Industrial-grade async data collection architecture
- Multi-skill chained evaluation (inspired by Sequential Dexterity, CoRL 2023)
- PPO + Domain Randomization for sim-to-real-ready policies
